Python 程序设计中，列表 list 是可变长有序序列，支持索引访问、切片和 append/extend/insert 等原地修改操作；元组 tuple 不可变，可作为字典键使用。字典 dict 以键值对存储，Python 3.7 之后保证插入顺序，查找平均时间复杂度为 O(1)。集合 set 用于去重和交并差运算。

Python 函数支持默认参数、关键字参数和可变参数 *args / **kwargs。使用默认参数时应避免可变对象作为默认值，例如 def f(items=[]) 会导致多次调用共享同一个列表，正确写法是使用 None 作为默认值并在函数内初始化。

面向对象编程中，类通过 class 关键字定义，实例方法第一个参数为 self。继承支持多继承，方法解析顺序遵循 MRO（C3 线性化）。魔术方法 __init__ 用于初始化，__str__ 定义字符串表示，__call__ 使实例可调用。

异常处理使用 try/except/else/finally 结构。except 应捕获具体异常类型而非裸 except，finally 中的代码无论是否发生异常都会执行，常用于资源释放。with 语句通过上下文管理器的 __enter__ 和 __exit__ 自动管理资源。

Python 的生成器通过 yield 关键字实现，按需产生值，适合处理大文件和流式数据，相比一次性构造列表可显著降低内存占用。迭代器协议包含 __iter__ 和 __next__ 两个方法。

常用标准库包括 os（文件和路径操作）、sys（解释器相关）、json（JSON 序列化）、datetime（日期时间）、collections（defaultdict、Counter 等容器）、itertools（迭代器工具）。第三方库numpy 用于数值计算，pandas 用于表格数据处理。

程序设计与问题求解课程强调把现实问题抽象为数据结构和算法步骤：先明确输入输出，再分解子问题，最后考虑边界条件和复杂度。课程项目通常使用函数式分解与模块化设计，每个模块职责单一。
